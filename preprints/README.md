## What counts as a benchmark

The benchmark across theoretical physics, mathematical physics, pure mathematics and cs.AI is
attained only by the full unconditional closure of one of the four target conjectures: strings,
seeds, Hodge and Yang–Mills. A result short of that, such as the uniform seed bound of 348
steps, is a sub-benchmark. Each sub-benchmark that holds gets a Zenodo DOI, a repository update
and a refreshed PDF here; each benchmark also gets a release of the engine image
`ghcr.io/creelie/bllm-engine` with a README update.

The 23 October 2026 refresh integrates the twelve exact interval certificates and the census-relative shortest-descent upper bound 346. The earlier arbitrary-descent bound 348 remains valid. The PDF was compiled locally with latexmk, rendered for visual review, and checked for unresolved references, overfull boxes and off-page text. RevTeX reported five float-placement warnings; their figures are present in the rendered output. The SHA-256 and page checks are in QA-2026-10-23.json. This refresh does not close the full target benchmark.
